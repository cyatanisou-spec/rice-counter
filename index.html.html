撮影のコツ（精度が大きく変わります）
  • 暗い色の無光沢の背景（黒いケント紙・マットなトレーなど）に米を一層に広げる。白い皿の場合は「背景が明るい」にチェック。
  • 真上から・影をつけずに撮影。粒同士をなるべく離し、重なりを減らすほど正確になります。
  • 画角いっぱいに粒が写るように撮ると、1粒のサイズが大きくなり誤差が減ります。
  • カメラの利用には HTTPS またはローカルファイルで開く必要があります（file:// ではカメラ不可の場合あり。その場合は写真を撮って「画像を選択」から読み込んでください）。
仕組みと精度

グレースケール化 → 平滑化 → 大津の二値化 → モルフォロジー解放 → 距離変換 + ワーターシェードで触れ合った粒を分離 → 面積フィルタでノイズ除去 → 「1粒あたりの面積の中央値」で割り戻して粒数を推定（分離できなかった塊も面積から概数を推定）。

同じアルゴリズムをPythonで合成画像（照明ムラ・影・密集・低コントラストの16ケース、30〜450粒）で検証した結果、標準的な撮影では平均絶対誤差約0.1%、難しい条件でも平均約2.0%・最悪約6.6%でした（修正前の同条件: 最悪約10.3%）。実写では粒の重なり方によってさらに誤差が大きくなることがあります。「推定値」としてお使いください。
